# 💌 Confession Website

A clean and emotional confession website designed to express feelings in a simple, elegant, and memorable way.  
This project focuses on smooth animations, minimal design, and a heartfelt user experience.

---

## ✨ Features

- 💖 Personalized confession message
- 🎞️ Smooth and subtle animations
- 🎨 Modern and minimal UI
- 📱 Fully responsive design
- ⚡ Fast performance

---

## 🛠 Tech Stack

- ⚛️ React / Next.js
- 🎨 Tailwind CSS
- 🎞️ Framer Motion (animations)
